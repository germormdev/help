Backup e ripristino

Il backup è un unico file con tutto il registro: viaggi, turni, rifornimenti, mezzi e documenti con le foto.

1/3

Fare un backup

«Impostazioni» → «Backup»: «Esporta database (backup)» salva il file, «Condividi backup» lo invia subito (email, messaggistica, cloud). Puoi fare il backup in qualsiasi momento senza interrompere il lavoro.

2/3

Ripristinare

«Importa database (ripristino)» sostituisce tutti i dati attuali con il file di backup. L'app controlla prima il file: un file estraneo o un backup creato con una versione più recente non verrà accettato. Su un telefono nuovo puoi ripristinare direttamente al primo passaggio del primo avvio.

3/3

Android e iPhone

Il backup è identico su Android e iPhone: un file salvato su uno si ripristina sull'altro.
