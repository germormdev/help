Ειδοποιήσεις και υπενθυμίσεις

Η εφαρμογή σας ενημερώνει για ό,τι βρίσκεται σε εξέλιξη και για ό,τι πλησιάζει.

1/3

Χρονόμετρα

Η αναμονή, ο ανεφοδιασμός και η εκφόρτωση συνεχίζουν να μετρούν και όταν η εφαρμογή είναι στο παρασκήνιο: το χρονόμετρο φαίνεται στη γραμμή ειδοποιήσεων. Πατήστε στην ειδοποίηση για να επιστρέψετε στην εφαρμογή.

2/3

Λήξη εγγράφων

Οι ειδοποιήσεις για τη λήξη εγγράφων έρχονται εκ των προτέρων καθώς και την ημέρα λήξης.

3/3

Άδειες

Αν οι ειδοποιήσεις, η κάμερα ή η τοποθεσία είναι απενεργοποιημένες, η εφαρμογή θα σας δείξει πού να τις επιτρέψετε στις ρυθμίσεις του τηλεφώνου.
