Sicherung und Wiederherstellung

Ein Backup ist eine einzelne Datei mit Ihrem gesamten Fahrtenbuch: Fahrten, Schichten, Tankvorgänge, Fuhrpark und Dokumente samt Fotos.

1/3

Backup erstellen

„Einstellungen“ → „Sicherung“: „Datenbank exportieren (Backup)“ speichert die Datei auf dem Gerät, „Backup teilen“ versendet sie direkt (E-Mail, Messenger, Cloud). Sie können jederzeit ein Backup erstellen — die laufende Arbeit wird nicht unterbrochen.

2/3

Wiederherstellen

„Datenbank importieren (Restore)“ ersetzt alle aktuellen Daten durch die Backup-Datei. Die App prüft die Datei vorab: Eine fremde Datei oder ein Backup aus einer neueren App-Version wird nicht angenommen. Auf einem neuen Telefon können Sie das Backup direkt im ersten Schritt beim ersten Start wiederherstellen.

3/3

Android und iPhone

Das Backup-Format ist auf Android und iPhone gleich: Eine Datei, die auf dem einen Gerät erstellt wurde, lässt sich auf dem anderen wiederherstellen.
