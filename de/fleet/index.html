Flotte

Die Flotte ist für Firmen mit mehreren Fahrzeugen und Fahrern. Der Flottenleiter gibt jedem Fahrer einen Einmal-Code. Damit bekommt das Telefon ein eigenes Fahrtenbuch der Flotte mit dem LKW und dem Anhänger der Flotte; was Sie dort eintragen, geht an die Flotte. „Mein Fahrtenbuch“ — Ihr eigenes Fahrtenbuch — bleibt, wie es ist, und bleibt Ihres.

1/6

Mit Code einer Flotte beitreten

Tippen Sie beim ersten Start auf „Ich fahre für eine Flotte — Code eingeben“. Später: Einstellungen → „Fahrerprofil“ → „Mit Code einer Flotte beitreten“.

Geben Sie den Code Ihres Flottenleiters ein und tippen Sie auf „Der Flotte beitreten“. Wenn der Flottenleiter Ihnen einen Link gesendet hat (my.vecturabook.com/fleet/join…), öffnen Sie ihn einfach auf Ihrem Telefon: Die App öffnet sich mit bereits eingetragenem Code. Sie können auch den gesamten Link in das Feld „Code“ einfügen.

Der Code funktioniert nur einmal und nur für eine begrenzte Zeit. Wenn die App meldet, dass der Code falsch, abgelaufen oder schon benutzt ist, bitten Sie Ihren Flottenleiter um einen neuen.

Ist das Telefon schon in einer anderen Flotte, fragt die App zuerst: Der neue Code schickt die letzten Einträge an diese Flotte und verlässt sie, ihr Fahrtenbuch bleibt nur zur Ansicht auf dem Telefon. Beenden Sie dort zuerst Fahrt und Schicht, sonst sagt die App „Beende zuerst die aktuelle Fahrt.“ oder „Beende zuerst die Schicht der Flotte.“ Ohne Internet ändert sich nichts.

2/6

Zwei Fahrtenbücher

Nach dem Beitritt hat das Telefon zwei Fahrtenbücher: „Mein Fahrtenbuch“ und das Fahrtenbuch der Flotte. Ein Streifen oben auf jedem Bildschirm zeigt, welches offen ist: blaugrau „Mein Fahrtenbuch“ oder lila mit dem Namen der Flotte. Tippen Sie auf den Streifen, um das andere zu wählen („Welches Fahrtenbuch?“). Wechseln geht nur, wenn keine Fahrt begonnen ist, sonst „Beende zuerst die aktuelle Fahrt.“

Schichten, Fahrten und Tankvorgänge aus dem Fahrtenbuch der Flotte gehen von selbst an die Flotte, sobald Internet da ist; „Jetzt an die Flotte senden“ in „Fahrerprofil“ sendet sofort. „Mein Fahrtenbuch“ geht nie an die Flotte — nur in Ihr eigenes Konto. Jedes Fahrtenbuch hat seine eigene Schicht, eigene Entwürfe und Timer.

Gibt Ihnen der Flottenleiter während einer Fahrt einen anderen LKW, kommt die Änderung nach dem Ende der Fahrt.

3/6

Eigener LKW

Fahren Sie mit Ihrem eigenen LKW für die Flotte, tippen Sie in „Fahrerprofil“ auf „Mit meinem eigenen LKW für die Flotte fahren“ und wählen Sie Ihren LKW („Fuhrpark“, „Mein Fahrtenbuch“). Er wird zum LKW im Fahrtenbuch der Flotte, und die Flotte sieht sein Kennzeichen bei Ihren Fahrten.

Kraftstoff für den eigenen LKW sind Ihre Kosten: Seine Tankvorgänge gehen immer in „Mein Fahrtenbuch“, auch wenn das Fahrtenbuch der Flotte offen ist. Ist keine eigene Schicht offen, bekommt „Mein Fahrtenbuch“ eine kurze abgeschlossene Schicht für die Zeit der Arbeit für die Flotte — so steht der Tankvorgang in Ihren Berichten und in Ihrem Konto. Kraftstoff für den LKW der Flotte und das Aggregat des Flotten-Anhängers geht an die Flotte. Ein Halt mit beidem wird als Ganzes gespeichert: Scheitert ein Teil, wird nichts gespeichert.

Der Kilometerstand des eigenen LKW läuft durch beide Fahrtenbücher weiter.

4/6

Flotte verlassen

„Fahrerprofil“ → „Flotte verlassen“. Beenden Sie zuerst die Schicht der Flotte („Beende zuerst die Schicht der Flotte.“). Die App sendet zuerst die letzten Einträge, dann verlässt sie die Flotte. Ohne Internet: „Keine Verbindung zum Server. Versuche es erneut, wenn du online bist.“ — es ändert sich nichts.

Danach bleibt das Fahrtenbuch der Flotte nur zur Ansicht auf dem Telefon: Der Streifen wird grau und zeigt „… · nur Ansicht“. „Fahrtenverlauf“, Tankvorgänge, Dokumente und PDF-Berichte sind da; Schaltflächen für Änderungen sind ausgeblendet, eine Schicht lässt sich nicht beginnen. An die Flotte geht nichts mehr. Um zurückzukommen, bitten Sie den Flottenleiter um einen neuen Code.

5/6

Flotte für den Eigentümer

Für den Flottenleiter. Aktivieren Sie „Eigentümer / Angestellt“ unter Einstellungen → „Fahrerprofil“: Dort erscheint die Zeile „Flotte“.

Die Flotte gehört zu Ihrem VecturaBook-Konto. Wenn das Telefon nicht angemeldet ist, zeigt der Bildschirm „Melde dich zuerst in deinem Konto an:“ — tippen Sie auf „Mit VecturaBook verbinden“ und melden Sie sich mit der E-Mail Ihres Kontos an. Hat das Konto keine Flotte, bietet der Bildschirm „Flotte anlegen“ an: Geben Sie „Name der Flotte“ ein und tippen Sie auf „Flotte anlegen“ — die kostenlose Testphase beginnt sofort.

Der Bildschirm zeigt „Fahrer“ — jeweils mit „Verbunden“ oder „Noch nicht verbunden“, LKW, Anhänger und der Anzahl von Schichten, Fahrten und Tankvorgängen — sowie den „Fuhrpark“ der Flotte. Darunter: „Fahrer hinzufügen“ mit dem Feld „Name des Fahrers“, „+ LKW hinzufügen“ („Kennzeichen“, „LKW-Typ“, „Aufbauart“) und „+ Anhänger hinzufügen“ („Kennzeichen“, Kompatibilität, „Aufbauart“). Dasselbe können Sie auch im Browser auf my.vecturabook.com tun.

Ohne Abo zeigt der Bildschirm „Flotten-Abo“ und „Fahrer“: Tippen Sie auf einen Fahrer für „Code erstellen“ und „Code an den Fahrer senden“ — das Telefon eines neuen Fahrers tritt der Flotte auch ohne Abo bei.

Bei einem Fahrer, der gegangen ist, steht statt „Verbunden“ „Hat die Flotte verlassen“ mit der Uhrzeit.

6/6

Fahrer

Tippen Sie auf einen Fahrer, um die Karte zu öffnen. „LKW“ und „Anhänger“: Wählen Sie aus dem Fuhrpark der Flotte und tippen Sie auf „Speichern“. Es werden nur Anhänger angeboten, die zum gewählten LKW passen. Das Telefon des Fahrers übernimmt die Änderung von selbst; während einer Fahrt — nach Ende der Fahrt.

„Code erstellen“ liefert einen einmaligen Code mit der Zeit, bis zu der er gültig ist. „Code an den Fahrer senden“ sendet den Code und den Link über einen Messenger. Der Code wird nur einmal angezeigt. Ein neuer Code überträgt den Fahrer auf ein neues Telefon: Das alte Telefon verlässt die Flotte.

Darunter stehen die „Schichten“, „Fahrten“ und „Tankvorgänge“ des Fahrers, die bei der Flotte eingegangen sind.

Die Karte eines Fahrers, der gegangen ist, zeigt „Hat die Flotte verlassen“ mit der Uhrzeit. Ein neuer Code von Ihnen holt den Fahrer zurück.
