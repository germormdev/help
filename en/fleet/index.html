Fleet

Fleet is for companies with several trucks and drivers. The fleet manager gives each driver a one-time code. With it, the driver's app gets the fleet's truck and trailer and sends a copy of shifts, trips and refuels to the fleet. The driver's own logbook stays on the phone.

1/4

Join a fleet with a code

On the first launch, tap "I drive for a fleet — enter code". Later: Settings → "Driver profile" → "Join a fleet with a code".

Enter the code from your fleet manager and tap "Join the fleet". If the manager sent you a link (my.vecturabook.com/fleet/join…), just open it on your phone: the app opens with the code already filled in. You can also paste the whole link into the "Code" field.

The code works only once and only for a limited time. If the app says the code is wrong, expired or already used, ask your fleet manager for a new one.

2/4

Driving for a fleet

After you join, the fleet's truck and trailer appear in Garage and become your truck and trailer — the first-launch questions are not needed. "Driver profile" shows "Fleet:" with the fleet's name, your truck and your trailer.

Shifts you open after joining go to the fleet; a shift opened before you entered the code stays yours. Copies of shifts, trips and refuels are sent automatically when there is internet; "Send to the fleet now" sends them right away. Your logbook on the phone does not change.

If the manager gives you another truck during a trip, the change comes after the trip ends. If a new code for you is used on another phone, this phone leaves the fleet.

3/4

Fleet for the owner

For the fleet manager. Turn on "Owner / Hired" in Settings → "Driver profile": the "Fleet" row appears there.

The fleet belongs to your VecturaBook account. If the phone is not signed in, the screen says "Sign in to your account first:" — tap "Connect to VecturaBook" and sign in with your account's email. If the screen says "This account has no fleet.", write to us via "Feedback / Bug Report" to open a fleet.

The screen shows "Drivers" — each with "Linked" or "Not linked yet", truck, trailer and the number of shifts, trips and refuels — and the fleet's "Garage". Below: "Add driver" with the "Driver's name" field, "+ Add Truck" ("Plate Number", "Truck Type", "Body Type") and "+ Add Trailer" ("Plate Number", compatibility, "Body Type"). The same can be done in your browser on my.vecturabook.com.

4/4

Driver

Tap a driver to open the card. "Truck" and "Trailer": choose from the fleet's garage and tap "Save". Only trailers that fit the chosen truck are offered. The driver's phone picks up the change by itself; during a trip — after the trip ends.

"Get code" gives a one-time code with the time it is valid until. "Send the code to the driver" sends the code and the link through a messenger. The code is shown only once. A new code moves the driver to a new phone: the old phone leaves the fleet.
