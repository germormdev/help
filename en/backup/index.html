Backup and restore

A backup is a single file containing your entire logbook: trips, shifts, refuels, vehicles, and documents with photos.

1/3

Create a backup

Settings → Backup: "Export Database (Backup)" saves the file, and "Share Backup" sends it right away (email, messenger, cloud). You can make a backup at any time without interrupting your work.

2/3

Restore

"Import Database (Restore)" replaces all current data with the backup file. The app checks the file first: an unrelated file or a backup made with a newer version of the app will not be accepted. On a new phone, you can restore right on the first step of the first launch.

3/3

Android and iPhone

The backup format is the same on Android and iPhone: a file made on one can be restored on the other.
