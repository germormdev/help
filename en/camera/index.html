VecturaBook — English

Camera: containers and seals

The camera reads container numbers, seal numbers, VINs, and odometer readings so you do not have to type them by hand.

1/5

Camera frame

Aim the number into the frame. Pinch the frame tight around the number so it reads better. Use "Turn the frame" for numbers written vertically. Tap outside the frame to take the shot.

2/5

Container Number

A container number has 4 letters and 7 digits. The app checks the check digit; if it does not match, the number is saved with the note "Number not validated" — check it with your own eyes.

3/5

Seal

The seal number is read from the printed text. If the seal has a barcode that does not match the printed number, the app uses the printed number: barcodes sometimes come from a different series.

4/5

Container Exchange

If you hand over a container to another driver at a stop and pick up theirs, log the exchange: which container was unloaded, which was loaded, the driver's name, and their truck plate number.

5/5

Photos

You can attach photos of paperwork at loading and unloading using "Document Photo". "VIEW PHOTOS" opens them full-screen.
