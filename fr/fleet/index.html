Flotte

Flotte s'adresse aux entreprises comptant plusieurs camions et chauffeurs. Le responsable de flotte remet à chaque chauffeur un code à usage unique. Grâce à lui, l'application du chauffeur récupère le camion et la remorque de la flotte et envoie une copie des journées, trajets et pleins à la flotte. Le propre carnet de bord du chauffeur reste sur le téléphone.

1/4

Rejoindre une flotte avec un code

Au premier lancement, appuyez sur « Je conduis pour une flotte — saisir le code ». Plus tard : Paramètres → « Profil du conducteur » → « Rejoindre une flotte avec un code ».

Saisissez le code fourni par votre responsable de flotte et appuyez sur « Rejoindre la flotte ». Si le responsable vous a envoyé un lien (my.vecturabook.com/fleet/join…), ouvrez-le simplement sur votre téléphone : l'application s'ouvre avec le code déjà rempli. Vous pouvez aussi coller l'ensemble du lien dans le champ « Code ».

Le code ne fonctionne qu'une seule fois et pour une durée limitée. Si l'application indique que le code est faux, expiré ou déjà utilisé, demandez-en un nouveau à votre responsable de flotte.

2/4

Conduire pour une flotte

Après avoir rejoint la flotte, le camion et la remorque de la flotte apparaissent dans Mon parc et deviennent votre camion et votre remorque — les questions du premier lancement ne sont pas nécessaires. « Profil du conducteur » affiche « Flotte : » avec le nom de la flotte, votre camion et votre remorque.

Les journées que vous ouvrez après avoir rejoint la flotte vont à la flotte ; une journée ouverte avant d'avoir saisi le code reste la vôtre. Les copies des journées, trajets et pleins sont envoyées automatiquement lorsqu'il y a une connexion Internet ; « Envoyer à la flotte maintenant » les envoie immédiatement. Votre carnet de bord sur le téléphone ne change pas.

Si le responsable vous attribue un autre camion pendant un trajet, le changement s'applique à la fin du trajet. Si un nouveau code vous concernant est utilisé sur un autre téléphone, ce téléphone quitte la flotte.

3/4

Flotte pour le propriétaire

Pour le responsable de flotte. Activez « Propriétaire / Salarié » dans Paramètres → « Profil du conducteur » : la ligne « Flotte » y apparaît.

La flotte appartient à votre compte VecturaBook. Si le téléphone n'est pas connecté, l'écran indique « Connecte-toi d'abord à ton compte : » — appuyez sur « Se connecter à VecturaBook » et connectez-vous avec l'adresse e-mail de votre compte. Si l'écran affiche « Ce compte n'a pas de flotte. », écrivez-nous via « Retour / Bug » pour ouvrir une flotte.

L'écran affiche « Chauffeurs » — chacun avec « Associé » ou « Pas encore associé », camion, remorque et le nombre de journées, trajets et pleins — ainsi que « Mon parc » de la flotte. En dessous : « Ajouter un chauffeur » avec le champ « Nom du chauffeur », « + Ajouter un camion » (« Immatriculation », « Type de camion », « Type de carrosserie ») et « + Ajouter une remorque » (« Immatriculation », compatibilité, « Type de carrosserie »). Vous pouvez faire de même dans votre navigateur sur my.vecturabook.com.

4/4

Chauffeur

Appuyez sur un chauffeur pour ouvrir sa fiche. « Camion » et « Remorque » : choisissez dans Mon parc de la flotte et appuyez sur « Enregistrer ». Seules les remorques compatibles avec le camion choisi sont proposées. Le téléphone du chauffeur applique la modification de lui-même ; pendant un trajet — après la fin du trajet.

« Obtenir un code » donne un code à usage unique avec l'heure jusqu'à laquelle il est valide. « Envoyer le code au chauffeur » envoie le code et le lien par messagerie. Le code n'est affiché qu'une seule fois. Un nouveau code transfère le chauffeur sur un nouveau téléphone : l'ancien téléphone quitte la flotte.

En dessous figurent les « Journées », « Trajets » et « Pleins » du chauffeur qui sont parvenus à la flotte.
