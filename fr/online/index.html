Programme en ligne

Le programme en ligne — my.vecturabook.com : le même carnet dans votre navigateur et sur vos autres appareils.

1/2

Connecter le téléphone

Paramètres → « Se connecter à VecturaBook ». Scannez le code QR affiché dans votre espace sur le site, ouvrez l'espace web dans le navigateur et confirmez sur le téléphone, ou saisissez le code affiché à l'écran. « Déconnecter ce téléphone » coupe la liaison.

2/2

Synchronisation

Le téléphone connecté envoie automatiquement les nouvelles entrées et reçoit les modifications de vos autres appareils. La ligne d'état indique « Tout est synchronisé » ou le nombre d'entrées en attente d'envoi. Sans réseau, les entrées attendent sur le téléphone.
