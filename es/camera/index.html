Cámara: contenedores y precintos

La cámara lee números de contenedor, precintos, códigos VIN y lecturas del cuentakilómetros para no tener que escribirlos a mano.

1/5

Marco de la cámara

Apunte el número dentro del marco. Ajuste el marco con dos dedos alrededor del número: así se lee mejor. «Girar el marco» sirve para números escritos en vertical. Toque fuera del marco para hacer la foto.

2/5

Número de contenedor

El «Número de contenedor» tiene 4 letras y 7 cifras. La aplicación comprueba el dígito de control; si no coincide, el número se guarda con el aviso «Número no validado» para que lo revise usted mismo.

3/5

Precinto

El «Número de precinto» se lee del texto impreso. Si el precinto tiene código de barras y no coincide con el número impreso, la aplicación toma el número impreso: a veces el código de barras pertenece a otra serie.

4/5

Intercambio de contenedores

Si en un punto entrega un contenedor a otro conductor y recoge el suyo, registre el intercambio: «Contenedor descargado», «Contenedor cargado», «Nombre del conductor» y «Matrícula del camión».

5/5

Fotos

Puede adjuntar al viaje fotos de los documentos de carga y descarga con «Foto de documentos». «VER FOTOS» las abre a pantalla completa.
